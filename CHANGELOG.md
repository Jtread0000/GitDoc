# Changelog

Share-point history for this manuscript. Each entry is **`version — date — title`**
followed by a bullet list of the **decisions** in that share, each linking to its
commit so you can see the diff (and recover anything a decision removed).
[`LOG.md`](LOG.md) is the fine-grained worklog of every touch; this file records
only declared share-points. Newest at the top.

## Versioning

A **version** is a share-point **you declare** when the document is shared — it does
not bump per commit. `MAJOR.MINOR.PATCH`: `0.1.0` is the baseline skeleton, **minor**
bumps are material milestones you'd re-share, **patch** bumps are smaller shares, and
`1.0.0` is the first final draft. Between versions, work accumulates as **decisions**
— coherent, document-wide edits carried as Word tracked changes and grouped by name
in the revision **author** field, so **Review → Show Markup → Specific People**
accepts or rejects one decision as a group. See [`docs/workflow.md`](docs/workflow.md).
