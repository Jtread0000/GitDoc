# Changelog

Versions here are **share-points you declare** — a milestone you choose to send out
(to an advisor, a co-author, a committee), not a bump for every edit. Add one entry
per version and tag a matching git release. Newest at the top.

Format loosely follows [Keep a Changelog](https://keepachangelog.com/) and
[Semantic Versioning](https://semver.org/): bump the **minor** for a meaningful
revision you'd re-share, the **patch** for small fixes, the **major** when the
document's scope or argument changes substantially.
