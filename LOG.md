# Worklog

A reverse-dated record of every notable touch to this manuscript — one short entry
per working session or meaningful change. It's the plain-text memory that outlives
any single draft: what changed, why, and where it left off. Newest entries at the
top.

Suggested entry shape:

```
## YYYY-MM-DD — short summary
- What changed (sections drafted, edits made, versions cut).
- Any decision worth remembering, or what to pick up next.
```
